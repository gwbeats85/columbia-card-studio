# Editable Columbia starter templates

Open new-arrivals.af or featured-card.af in Affinity. Both contain named vector, text, and embedded-image layers. Canvas: 1080×1350, 72 dpi. SVG versions are also supplied. Arial is used for editable copy. The existing website logo remains a raster image.

Background PNGs were exported from Affinity and are consumed by the Posts workspace. To make your own background, hide Copy, Photo, and Brand groups, export the complete canvas to PNG, then import with Custom PNG. The app's text/photo layout remains defined in code. These are starter studies; Ty Cobb is an archival demo, not a statement of inventory or price.
